# CrazySMP Mods

A collection of Paper 1.21.11 plugins for the CrazySMP server.

## Mods

### 1. CoordinateAnnouncer
Announces player coordinates in chat at configurable intervals with a 10-second countdown.

**Commands**: `/ca` (alias for `/coordinateannouncer`)
**Permission**: OP-only

See [CoordinateAnnouncer/README.md](CoordinateAnnouncer/README.md) for full docs.
